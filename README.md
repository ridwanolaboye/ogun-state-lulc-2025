# Ogun State Land Use and Land Cover Classification 2025

This project presents a land use and land cover classification of Ogun State, Nigeria, using 2025 satellite imagery.

## Project Overview

The project focuses on identifying and mapping major land cover classes across Ogun State, including built-up areas, vegetation, water bodies, and bare land.
